# Aura & Wax - Artisanal Candle E-Commerce Practice Website

A professional, fully responsive e-commerce practice website built with HTML, CSS, and JavaScript.

## Features
- **Product Showcase & Filtering**: Filter candles by fragrance family (Woody, Floral, Warm) or live-search by keyword.
- **Interactive Product Modal**: Clicking any product opens a detailed view showing fragrance pyramids (top, mid, base notes) and pricing.
- **Slide-over Shopping Bag**: Add items, adjust quantities, and watch the live progress bar update for free shipping thresholds ($75).
- **Responsive Design**: Looks stunning on mobile devices, tablets, and desktops.

## How to View via GitHub Pages
1. Go to your repository **Settings**.
2. Click on **Pages** in the left sidebar.
3. Under **Build and deployment**, select `Deploy from a branch`.
4. Choose the `main` branch and `/ (root)` folder, then click **Save**.
5. Your website will be live in a minute at `https://<your-username>.github.io/<repository-name>/`!
